# Energy Optimizer 1.0

Адаптивний вебзастосунок для математичного моделювання розподілу обмеженого запасу електроенергії.

## Запуск локально

1. Встановіть Python 3.10 або новіший.
2. Розпакуйте архів.
3. Відкрийте термінал у папці проєкту.
4. Виконайте:

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

5. Встановіть залежності:

```bash
pip install -r requirements.txt
```

6. Запустіть:

```bash
streamlit run app.py
```

Застосунок відкриється у браузері. Для доступу зі смартфона в тій самій Wi-Fi мережі можна запустити Streamlit із параметром `--server.address 0.0.0.0`, а потім відкрити локальну IP-адресу комп'ютера з порту 8501.

## Публікація в інтернеті

Проєкт можна завантажити до GitHub і розгорнути на Streamlit Community Cloud. Після розгортання буде створено посилання, доступне з комп'ютера та смартфона.

## Межі першої версії

Модель працює з часовими інтервалами по 1 годині та двійковим рішенням «працює / не працює». Вона не моделює пускові струми, змінну потужність, циклічність холодильника, мінімальні безперервні інтервали роботи та одночасні короткі піки навантаження. Ці обмеження потрібно описати в науковій роботі та врахувати під час наступного вдосконалення.
